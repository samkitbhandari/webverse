# Type Certification Plan - Helios Shuttle Platform

## Regulatory basis

Type Certification is granted against UNECE R100 for electric powertrain safety.

UNECE R100 governs the thermal propagation requirements for traction batteries.

## Submission

Type Certification submission is scheduled in 4 months.

Type Certification requires Battery Pack BP-7 to demonstrate thermal compliance
across the full duty cycle.

Type Certification depends on Thermal Architecture A7.

## Test campaign

Thermal propagation testing lead time is 45 days.

Type Certification cost is 34 lakh.

## Consequences

Fleet Deployment Phase 2 depends on Type Certification.

There is a critical risk of schedule slip if the certification submission is
rejected on thermal grounds.

## Decision

We have decided to submit Type Certification against the current thermal
envelope because the measured margin was accepted in the Phase 1 review.
