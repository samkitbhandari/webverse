# Thermal Requalification Test Report - Chamber B

## Configuration

Battery Pack BP-7 was retested with the revised coolant duct and an uprated
blower.

## Results

Measured Battery Pack BP-7 max operating temperature reached 58 degC across the
full duty cycle.

Battery Pack BP-7 energy density is 171 Wh after the duct revision.

Thermal Architecture A7 unit cost is 74000 INR with the uprated blower fitted.

## Assessment

Battery Pack BP-7 is compliant with the revised thermal envelope.
