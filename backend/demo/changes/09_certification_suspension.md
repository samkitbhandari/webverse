# Notified Body Bulletin - Thermal Case Review

## Status change

Type Certification is suspended pending resubmission of the thermal case.

Thermal Architecture A7 is no longer compliant with the revised operating
envelope.

## Scope

Charging Hub North remains operational and is unaffected by this bulletin.

## Required action

Meridian Transit Authority requires that Battery Pack BP-7 must remain below
60 degC across the full duty cycle before Type Certification is reinstated.

There is a critical risk of schedule slip if the resubmission is not accepted
at first review.
