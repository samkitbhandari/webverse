# Programme Budget Variance - Quarter 3

## Forecast

Fleet Deployment Phase 2 cost is 520 crore at the current run rate.

## Cause

Volta Cells Ltd unit cost is 3980 INR following the cathode surcharge.

Type Certification cost is 51 lakh after the second test campaign was added.

## Consequence

There is a critical risk of programme descope if the overrun is not recovered
before the next funding review.

Meridian Transit Authority requires that Fleet Deployment Phase 2 cost must not
exceed 480 crore.
